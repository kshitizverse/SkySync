Privacy Policy

Last updated: August 2026

1. Information We Collect

SkySync collects only the information necessary to provide our cloud storage service:

  • Account Information: Name, email address, and phone number (via Telegram authentication)
  • File Data: Files you upload to our Telegram-backed storage infrastructure
  • Usage Data: Activity logs including login times, file operations, and IP addresses
  • Session Data: Temporary session cookies for authentication (stored locally on server)

2. How We Use Your Data

  • To provide and maintain the SkySync cloud storage service
  • To authenticate your identity and prevent unauthorized access
  • To track file operations for security and auditing purposes
  • To improve our service and user experience

3. Data Storage & Security

File data is stored via the Telegram API as an underlying storage layer. We implement:

  • End-to-end encrypted session cookies
  • Server-side session management with secure storage
  • Rate limiting and brute-force protection on authentication endpoints
  • Security headers (X-Content-Type-Options, X-Frame-Options, X-XSS-Protection)
  • Password strength validation
  • Activity logging for audit trails

4. Data Sharing

We do not sell, trade, or share your personal information with third parties, except:

  • When required by law or legal process
  • When you explicitly share files via shareable links
  • To protect the rights and safety of SkySync and its users

5. Data Retention

  • Account data is retained as long as your account is active
  • Files in trash are permanently deleted after 30 days
  • Activity logs are retained for security auditing purposes
  • Share links expire based on your configured expiration period

6. Your Rights

You have the right to:

  • Access, update, or delete your personal information
  • Download all your stored files
  • Revoke share links at any time
  • Request complete account deletion

Frequently Asked Questions

How do I upload files?

Click the upload button in the dashboard toolbar, or drag and drop files onto the dropzone area. You can also select multiple files at once.

What's the maximum file size?

The default maximum file size is 100 MB. This can be configured by the system administrator.

How do file shares work?

Click the share icon on any file to generate a shareable link. You can configure:

  • Can View: Recipients can see file details
  • Can Download: Recipients can download the file
  • Expiration: Links expire after a set number of days

How do I recover deleted files?

Go to the Trash view in the sidebar. Deleted files are kept for 30 days. Click "Restore" to recover a file, or "Delete Permanently" to remove it immediately.

How do favorites work?

Click the star icon on any file to add it to your favorites for quick access. You can view all favorites from the Favorites section in the sidebar.

Can I rename files?

Yes, right-click on a file and select "Rename" from the context menu, or click the rename action in the file card.
